# Cube.c

A 3D spinning ASCII cube rendered in the terminal using pure C, built from scratch with 3D rotation matrices, perspective projection, Z-buffering, and normal-based diffuse lighting.

## Features

- **Pure C Implementation:** Uses only standard C libraries (`math.h`, `stdio.h`, `string.h`, `unistd.h`).
- **3D Rotation:** Real-time rotation around the X, Y, and Z axes.
- **Perspective Projection:** Maps 3D coordinates to a 2D terminal grid using $1/z$ depth scaling.
- **Z-Buffering:** Tracks depth per character cell so closer surfaces properly occlude farther ones.
- **Diffuse Lighting:** Calculates real-time face brightness using the dot product of rotated surface normals and a light vector.

---

## How It Works

### 1. Coordinate System & Cube Geometry
The cube is centered at the origin $(0, 0, 0)$ so rotations happen cleanly around its center. All 6 faces are generated by fixing one axis at $\pm\text{cubeWidth}$ while sweeping the other two axes across the $xy$, $xz$, and $yz$ planes.

### 2. 3D Rotation
Each point $(x, y, z)$ on the cube's surface is rotated sequentially around the X, Y, and Z axes:

- **Around the X-axis:**
  $$x' = x, \quad y' = y\cos\theta - z\sin\theta, \quad z' = y\sin\theta + z\cos\theta$$
- **Around the Y-axis:**
  $$x' = x\cos\theta + z\sin\theta, \quad y' = y, \quad z' = -x\sin\theta + z\cos\theta$$
- **Around the Z-axis:**
  $$x' = x\cos\theta - y\sin\theta, \quad y' = x\sin\theta + y\cos\theta, \quad z' = z$$

### 3. Perspective Projection (3D to 2D)
After pushing the cube away from the camera ($z \leftarrow z + \text{distanceFromCam}$), the 3D point is projected onto the 2D terminal screen using $\text{ooz} = \frac{1}{z}$ and a scaling constant $K_1$:

$$x_p = K_1 \cdot \text{ooz} \cdot x, \qquad y_p = K_1 \cdot \text{ooz} \cdot y$$

To map this onto an $80 \times 30$ terminal centered at $(40, 15)$ (with a $2\times$ horizontal multiplier to compensate for terminal character aspect ratio):

```c
screenX = (int)(WIDTH / 2 + K1 * ooz * x * 2);
screenY = (int)(HEIGHT / 2 - K1 * ooz * y);
```

### 4. Z-Buffering
To ensure only the closest visible surface is drawn at each terminal cell, the renderer stores the largest `ooz` (closest depth) in a Z-buffer:

```c
if (ooz > zBuffer[index]) {
    zBuffer[index] = ooz;
    buffer[index] = character;
}
```

### 5. Lighting & ASCII Shading
Each face has an outward surface normal $\mathbf{N}$ that is rotated alongside the cube. Brightness is computed using the dot product between the rotated normal $\mathbf{N}$ and the light direction $\mathbf{L}$:

$$\text{brightness} = \mathbf{N} \cdot \mathbf{L}$$

The resulting value is mapped to a 12-level ASCII shade ramp from darkest to brightest:

```c
const char *shades = ".,-~:;=!*#$@";
```

## Build & Run

### Linux / macOS
```bash
gcc cube.c -o cube -lm
./cube
```

### Windows (MinGW)
Replace `#include <unistd.h>` with `#include <windows.h>` and `usleep(16000);` with `Sleep(16);`, then compile and run:
```bash
gcc cube.c -o cube.exe -lm
cube.exe
```

Press `Ctrl + C` to exit.

## Customization

You can tweak the constants at the top of `cube.c` to adjust the look and feel:

| Variable | Default | Description |
| :--- | :--- | :--- |
| `WIDTH` / `HEIGHT` | `80` / `30` | Terminal canvas dimensions |
| `cubeWidth` | `10.0f` | Half-length of each cube edge |
| `distanceFromCam` | `60.0f` | Distance between the camera and the cube |
| `K1` | `35.0f` | Projection scale / zoom factor |
| `incrementSpeed` | `0.6f` | Surface sampling resolution (lower = denser) |
